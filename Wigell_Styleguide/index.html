Wigell Styleguide

I denna styleguide finns det vissa exempel på hur en hemsida kan göras, med kodexempel och liknande.

Färgschema

På färgschemat kan vi se vilka färger och deras färg koder som vi använder under skapandet av denna hemsida, står även vad dem används till.

Primär #1B3A6B
Accent #C0392B
Bakgrund #F4F5F7
Yta #FFFFFF
Text #1A1A1A
Dämpad text #6B7280
CSS — Färgvariabler 
:root {
    --color-primary:    #1B3A6B;
    --color-accent:     #C0392B;
    --color-bg:         #F4F5F7;
    --color-surface:    #FFFFFF;
    --color-text:       #1A1A1A;
    --color-text-muted: #6B7280;
    --color-border:     #E2E4E8;
}

Typografi

Vi använder Syne för rubriker och Source Sans 3 för brödtexten.

Välkommen till Wigell

Syne 700 · 2.5rem

Om koncernen

Syne 700 · 2rem

Våra tjänster

Syne 600 · 1.5rem

Kontakt och support

Syne 600 · 1.2rem

Brödtext används för löpande innehåll på sidan. Håll meningar korta och tydliga så att användaren enkelt kan ta till sig informationen.

Source Sans 3 · 1rem · line-height 1.7

<h1>Rubrik H1</h1>
<h2>Rubrik H2</h2>
<h3>Rubrik H3</h3>
<h4>Rubrik H4</h4>
<p>Brödtext</p>

Knappar

Här har vi exemplar på hur knappar kan se ut, och vad färger och liknande kan påverka deras förtydelse.

Standard — används för olika saker
Funktion — för verktyg som skriv ut, exportera
Positiv — för skapa, spara, bekräfta, OK
Negativ — för avbryt, stäng, radera
HTML — Knappar 
<button class="btn btn--standard">Standardknapp</button>
<button class="btn btn--function">🖨️ Skriv ut</button>
<button class="btn btn--positive">✓ Spara</button>
<button class="btn btn--negative">✕ Ta bort</button>

Tabeller

Här har vi två exempel på listor en är för användare och den andra är för data.

Lista-tabell

För längre listor med få kolumner, t.ex. en användarlista.

Namn Roll Status
Bergitta Svensson Administratör Aktiv
Erik Lundgren Användare Aktiv
Jessica Olson Användare Inaktiv

Data-tabell

För tät data med många kolumner, t.ex. bokningar eller statistik.

ID Datum Typ Användare Belopp Status
#1042 2025-05-10 Faktura Bergitta Svensson 320 kr Betald
#1043 2025-05-11 Order Erik Lundgren 160 kr Väntande
#1044 2025-05-12 Faktura Jessica Olson 480 kr Obetald

<table class="table table--list">
    <thead>
        <tr>
            <th>Kolumn</th>
        </tr>
    </thead>
    <tbody>
        <tr>
            <td>Data</td>
        </tr>
    </tbody>
</table>

Meddelanden

Meddelanden visar för användaren vad som har hänt symboler är extra bra för om personen har nedsatt syn på något sätt.

✓ Sparat! Dina ändringar har sparats.
ℹ Info: Kommande nyheter till sidan eller generell information.
⚠ Varning: Du har osparade ändringar.
✕ Fel: Något gick fel. Försök igen eller kontakta support.
HTML — Meddelanden 
<div class="alert alert--success">✓ Sparat!</div>
<div class="alert alert--info">ℹ Information</div>
<div class="alert alert--warning">⚠ Varning</div>
<div class="alert alert--error">✕ Fel</div>

Laddningsindikator

Visa laddningsindikatorer när systemet arbetar och användaren behöver vänta.

Spinner — för generell laddning
Progressbar — när procent är känd (65%)
Skeleton — platshållare medan innehåll laddas
HTML — Laddning 
<div class="spinner"></div>

<div class="progress-bar">
    <div class="progress-bar__fill" style="width: 65%;"></div>
</div>

<div class="skeleton"></div>

Paneler

Paneler grupperar relaterat innehåll och ger visuell feedback om status.

✓ Positiv panel

Används för att bekräfta en lyckad åtgärd eller visa positiv information, t.ex. att en ansökan är godkänd.

ℹ Neutral panel

Används för allmän information utan specifik status, t.ex. en instruktionsruta för användaren.

✕ Negativ panel

Används för att varna om problem eller visa negativ status, t.ex. att en betalning misslyckades.

HTML — Paneler 
<div class="panel panel--positive">
    <h4>Positiv panel</h4>
    <p>Innehåll...</p>
</div>

<div class="panel panel--neutral">
    <h4>Neutral panel</h4>
    <p>Innehåll...</p>
</div>

<div class="panel panel--negative">
    <h4>Negativ panel</h4>
    <p>Innehåll...</p>
</div>
